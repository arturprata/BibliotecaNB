# 📚 BibliotecaNB

Sistema de gerenciamento de biblioteca desenvolvido em **Java**,
utilizando **Programação Orientada a Objetos (POO)** e o padrão de
projeto **DAO (Data Access Object)**, com integração a banco de dados
**MySQL**.

------------------------------------------------------------------------

## 🚀 Funcionalidades

-   Cadastro de usuários
-   Cadastro de livros
-   Controle de empréstimos e devoluções
-   Operações completas de CRUD
-   Persistência de dados com MySQL

------------------------------------------------------------------------

## 🛠️ Tecnologias Utilizadas

-   Java
-   MySQL
-   JDBC
-   Programação Orientada a Objetos (POO)
-   Padrão DAO

------------------------------------------------------------------------

## 📂 Estrutura do Projeto

-   `model/` → Classes de entidade (Usuário, Livro, Empréstimo)
-   `dao/` → Acesso a dados (DAO)
-   `service/` → Regras de negócio
-   `main/` → Execução da aplicação

------------------------------------------------------------------------

## ⚙️ Como Executar

1.  Clone o repositório:

``` bash
git clone https://github.com/arturprata/BibliotecaNB.git
```

2.  Configure o banco de dados MySQL:

-   Crie o banco
-   Atualize as credenciais no projeto

3.  Compile e execute:

``` bash
javac Main.java
java Main
```
